# Ad Inspiration

A curated swipe file of static image ads. Phase 1 of the workflow (`competitor-analysis`) reads every image here, analyses the visual + copy, logs it to the "Ad Inspiration" Google Sheet tab, and translates the patterns into concepts for your brand.

## What's included

This template ships with a starter set of strong static ads from a range of DTC brands across supplements, personal care, food and home. They were picked because they follow the principles in `static-ads-strategy` (skimmability, objection handling, social proof, scroll-stopping imagery, copy simplicity). Those principles carry across categories, so the set is useful for most brands as-is. Keep the ads that fit your brand and delete the rest.

## Add your own

Ads you add here are higher-signal than the starter set:

- **Competitor ads** you've found in the Meta Ad Library that are clearly performing (long-running, many variations)
- **Cross-category ads** with a format or hook you want to borrow
- **Your own past winners.** Prefix them with your brand name (e.g. `yourbrand-summer-bundle-comparison.jpg`) so they're recognised and studied especially closely.

Use descriptive kebab-case filenames: `<brand>-<what-the-ad-does>.jpg`. The filename is used for de-duplication, so each image is only analysed once.
