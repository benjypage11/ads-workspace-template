# Generated Assets

Created by the workflow. Don't add files here by hand.

- `creative-brief-current.md`: the approved Creative Brief for the current batch (written in Phase 2, trimmed at the Phase 2.5 review)
- `phase3a-state.json`: per-creative state (prompts, Drive links, copy) used to resume generation and to log to Sheets
- `<Concept>-<Treatment>-<Variant>-<SQ|VT|HZ>_<DD-MM-YYYY>.png`: the generated creatives in square, vertical and horizontal sizes

Everything in this folder except this README is git-ignored.
